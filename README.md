## 🚀 Installation & Run

1. **Clone repository:**
   ```bash
   git clone https://github.com/lookingglass/port-inspect
   cd port-inspect
   ```

2. **Make script executable:**
   ```bash
   chmod +x port-inspect.sh
   ```

3. **Run tool:**
   ```bash
   ./port-inspect.sh <port>
   ```
